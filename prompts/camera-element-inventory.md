# カメラ画像の写り込み要素インベントリ

これは異変案ではなく、現行8枚を見たままに分解した観察台帳。各画像を左上から右下へ辿り、物・面・光・文字・影・反射・画面端で切れているものを別々に記録する。

## 座標の読み方

- 原点 `(0,0)` は画像左上、右下は `(1000,1000)`。矩形は `(x1,y1)–(x2,y2)`。
- 矩形は物体の見えている範囲の目測。圧縮/ぼけ/重なりで境界が曖昧なものもあるため、ピクセル精度の切り抜き座標ではない。目測差はおよそ画像幅/高さの±2%を見込む。
- ピクセル座標への換算は `x_px = x_norm × width / 1000`, `y_px = y_norm × height / 1000`。元画像寸法を必ず併記する。
- 「不鮮明」「〜状」は、画像から確定できないものを断定しないための記録。

## 確度・再確認対象

- CAM 01/02/03/04/05/06/07/08は、ゲームに使われている現行画像そのものを対象にした。
- 文字が特に不鮮明なのはCAM 01の吊り看板、CAM 02/03の下段看板文字、CAM 04の左上緑看板、CAM 05の緑看板、CAM 06の店名看板、CAM 07/08の丸看板。文字異変を作る時は、この観察メモだけで元文字を決めず、原画像から別途確認する。
- 小物に見えるものが絵の生成ノイズ/圧縮ノイズと区別できない時は、独立した物体として断定せず、ここで「状」「不確実」と記した。
