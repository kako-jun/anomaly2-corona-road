# 異変の多様化：初回試作

新しいカメラマスターから built-in image generation で猫、階段一段増、タイル模様、ガラスだけの傘をそれぞれ生成。各 `*-source.png` は生成元、`*-mask.png` は不定形マスク、`*-preview.png` は基準写真への検証合成。ゲーム候補は `assets/anomaly-overlays/` の透過差分と位置台帳。

猫とタイルは原寸で存在を確認。階段は段全体が再生成され、一段だけ増えたか確認できない。ガラスの傘は実物ではなく反射に見えるか不確実。後者2件は不採用を含め再検討。全件ゲーム画面・ライブ blink 未確認。

第2回: 水たまり、壁の紙、鉢の色・形・複製、床タイルの色、吊り折り鶴を試作。原寸プレビューを保存し、差分の再構成は全画素一致。ノブ移動は元のノブも残るため `handle-rejected.webp` として不採用。ゲーム画面・ライブ blink は全件未確認。
