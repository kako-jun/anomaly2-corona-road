# 看板架空化の試作

CAM02 の喫茶店名を他作品 nostalgic にちなむ「ノスタルジック」、CAM06 の飲食店名を machigai-salad にちなむ「まちがいサラダ」とする案。built-in image generation に基準写真と文字指定を渡し、看板付近のみをぼかしマスクで元写真に合成した。`cam02-preview.png` と `cam06-preview.png` は途中案で、公開用baselineではない。

同じ店舗は複数カメラに写る。CAM02右上の看板断片、CAM03の緑看板、他カメラの丸看板、CAM04/05のクリーニング看板等の処理が未完了。マークは他作品の正規ロゴをまだ取り込んでいない。8枚を一貫して監査し、文字と図柄を揃えたうえでマスター化し、全異変差分を新baselineで再検証する。Corona Roadの名前はそのまま。

2026-10-29 レビュー: 初版は不採用。ノスタルジックはゴシック体がデジタル合成に見え、まちがいサラダは元店の人物風ロゴが残っていた。正規アイコン（エビとサラダ）を参照し、古い手描き看板として再試作する。

v2 は `cam02-v2-preview.png`（手描き風に再生成）と `cam06-v2-preview.png`（machigai-salad のエビとサラダの実アイコンを参照し旧ロゴごと描き直し）。どちらも元画像に看板部分だけ合成した試案。原寸で形は確認したが、昭和らしさと文字はユーザー確認待ち。他カメラの同一店舗は未統一。

v3: `cam02-v3-preview.png` は右上の見切れた旧名も「ノスタ…」に差し替え、v2の自立看板と揃えた。`cam06-v3-preview.png` は料理屋の看板部分だけ彩度・明度を抑え、わずかにぼかして写真の質感になじませた。いずれも元写真を下地に局所マスク合成。公開マスターへの反映および他カメラの統一は未実施。

CAM06 v4 は文字の鮮明さをさらに落とし、看板内部に光が回るよう柔らかいにじみを追加した試案。変更は看板マスク内のみ。`cam06-v4-preview.png` を原寸で確認、他カメラ・ゲーム画面での確認と公開マスター化は未了。

CAM06 v4 はぼやけすぎとの指摘で不採用。v5 (`cam06-v5-preview.png`) はぼかしを弱め、光のにじみも控えめにした再調整。公開マスターには未反映。

CAM02 v4 (`cam02-v4-preview.png`) は自立看板と見切れた看板に控えめな光のにじみを追加。CAM06 v6 (`cam06-v6-preview.png`) は元の橙色四角・白い丸を保ち、丸の中に小さなエビのマークと細い手描き風文字を配置した試案。看板面の部分合成であり公開マスターには未反映。

CAM02 v4 と CAM06 v6 はユーザーが承認し、各 WebP マスターに反映済み。両 WebP は承認プレビューと全画素一致。既存異変マスクと看板変更マスクの重なりはゼロ。CAM03等の同一店舗や他店の看板統一は引き続き未完了。

CAM03: 同じ喫茶店の看板を「ノスタルジック」に統一した `cam03-preview.png` を、新聞を含まない `public/images/cam3.webp` のマスターに反映済み。新聞差分とのマスクの重なりはゼロで、新マスターに新聞差分を重ねたプレビューも確認した。
