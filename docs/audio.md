# 音声（#79）

音の異変（`anomaly_type: sound`）を鳴らすための基盤と、台帳の sound 18件の調達方針の分類。**異変そのもの（内容・phase・memo）の正本は `prompts/anomalies.yaml`**。ここは id で参照するだけで、台帳の文面は写さない。

## 試作中（#79・#389）

通常音として監視中のハム、ボタン、つまみ、紙、カメラ切替時の雑音を合成する。RT-SND-01・02・03・04・05・09・10・11、CR-RZ-07〜09、CR-SH-05 はカメラ表示中に再生し、カメラ移動または報告で停止する。音色・音量は仮で、スマホ実機での聴取と調整が必要。カメラ切替時の映像ノイズ強調は未実装。RT-SND-08 は未実装。**RT-SND-01（環境音消失）は kako-jun の耳で実機確認待ち**（通常は控えめなハムなので、スマホのスピーカーでそれが消えたことが知覚できるか未確認）。声素材5件は再生基盤に接続済みだが、素材の試聴確認前のため台帳上は planned のまま。

試聴の指摘を受け、足音・食器・ラジオ等の小さな異変音を増幅し、ボタン音は短い乾いたノイズへ調整した。通常時は控えめな単一ハムのみとし、重ね合わせる環境音を設けない。環境音消失の異変中はハムを止める。短い異変音は9〜25秒の不規則な間隔で音色や間合いを変えて繰り返し、発見まで継続する。音色と聞こえやすさは再試聴待ち。

## 基盤（実装済み）

| 部品                         | 役割                                                                                                                                                                                                                                                                                                                                                                                                                                                            |
| ---------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `src/utils/audioEngine.ts`   | 共有 `AudioContext` 1つ + マスター GainNode の薄いラッパ。`unlock()`（ユーザー操作で作成・resume）、`setVolume`（0〜100。0 が無音。別のミュートは持たない）。作成・resume・ノード操作の失敗は握りつぶして無音で続行する                                                                                                                                                                                                                                         |
| `installAudioUnlock`         | 操作（`pointerdown` / `keydown` / `touchend`）とページが visible に戻った時に、running でなければ `unlock()`（resume）。`statechange` で running を離れた時も再 resume。リスナーは1回だけ付け、running の間は何もしない（iOS のバックグラウンド割り込みから復帰できる）。`src/main.tsx` から `initGameAudio()` が呼ぶ                                                                                                                                           |
| `src/utils/audioSettings.ts` | 音量の保存。セーブの `settings.volume`（0..100、既定 70）。0 がミュート。古いセーブの `settings.muted: true` は 0 として読み、次の保存で捨てる。START OVER で残り、引き継ぎコードの取り込みでは端末の値が残る（他の `settings` と同じ。`docs/save-data.md`）                                                                                                                                                                                                    |
| `src/utils/synthSounds.ts`   | WebAudio 合成（発振器・フィルタ付きノイズ・ゲイン包絡）のレシピ。常時: `hum`（50/100/300Hz の控えめな単一ハム）・`wobble`（RT-SND-10、300Hz 成分を 0.4Hz で揺らす）・`humGrow`（RT-SND-02、同じ構成が大きくなる）・`buzz`。異変・効果音: `knock` `footsteps` `chime` `shutter` `stinger` `beat`（CR-RZ-08）`dishes`（RT-SND-11）`radio`（CR-SH-05）。操作音: `button` `knob` `paper` `static`。`playSynth(engine, name)` は未 unlock なら null を返し何もしない |
| `src/utils/voiceSounds.ts`   | 声素材5件（`VOICE_IDS`）の再生。`probeVoices` が metadata だけで長さを調べ、60秒以上の声だけ抽選可能にする。デコードは必要な1本だけ（`holdVoice` / `releaseVoice`）。`playVoice` が終端1秒重ねの複製を先読みで予約し、`stop()` で未来の複製も止める。ファイルの選択は下の「対応形式」                                                                                                                                                                           |

- 異変音は選ばれたカメラを見ている間だけ鳴らす。カメラ切替・報告で `SoundHandle.stop()` が出力を遮断する。
- レシピの音色・音量は暫定。kako-jun の実機の耳で調整する（聴覚の最終確認は人）。
- 実ブラウザ（Chromium）で、ジェスチャー前は context なし、クリック後 `running`、`buzz` 再生中は出力に信号があり、音量 0 で出力が 0、戻すと復帰、`stop()` で 0 になることを AnalyserNode で確認済み。

## 音量つまみ VOL（実装済み、#79）

kako-jun の決定（2026-11-12）: ミュート UI は案B（つまみ）。別のミュートボタンは作らない。

- 操作部の明るさ BRIGHTNESS・コントラスト CON の隣に、3つ目のつまみ `VOL`（アクセシブルな名前は Volume）。操作は既存つまみと同じ（ドラッグ・矢印キー・Home/End・タッチ）。範囲 0〜100、既定 70（タップ・Enter・Space で 70 に戻る）。`Cabinet` が `gameAudio.setVolume` で即座にマスターへ反映し、止まって 300 ms 後（または画面を離れる時）に `settings.volume` へ保存する。
- 音量 0 がミュート。`audioEngine` に別のミュート状態は無く、`muted` は廃止した。古いセーブに `settings.muted: true` があれば 0 として読み、次に音量を保存した時に `muted` を捨てる（実データを壊さず、黙っていたい人は黙ったまま）。スキーマ `v` は上げない。
- 音量 0 の間は音の異変（`anomaly_type: sound`）を出現の抽選から外す（#77 の出現基盤の PR の範囲）。異変が出た後に 0 にしても出たままで、報告で解除できる。
- つまみを回す操作音は #389 の通常効果音として鳴らす。
- 筐体の寸法: つまみは同じ横一列の3つ目なので高さは変わらず、`.tube` の定数・`retro.test.ts` の項は不変。

## 台帳 sound 18件の調達分類

合成 = 基盤の WebAudio 合成で作れる（素材ファイル不要）。素材 = 録音または生成した音声ファイルが要る。

**合成で作れる（13件）**

| 台帳 id   | 実装（`SOUND_EFFECTS` のレシピ名 / `HUM_MODES`）                                    |
| --------- | ----------------------------------------------------------------------------------- |
| RT-SND-01 | `HUM_MODES` `'off'`。通常のハムの effect を止めるだけ（蛍光灯もマスター低下も無い） |
| RT-SND-02 | `HUM_MODES` `'loud'`。`humGrow`（同じハムが大きくなる）                             |
| RT-SND-03 | `buzz`                                                                              |
| RT-SND-04 | `footsteps`（間隔・音程・音量が変わる低域ノイズの足音）                             |
| RT-SND-05 | `knock`（3打）                                                                      |
| RT-SND-08 | 未実装。新規の音は不要。他カメラ用のミックス経路（出す側の設計）が要る              |
| RT-SND-09 | `stinger`                                                                           |
| RT-SND-10 | `HUM_MODES` `'wobble'`。`wobble`（300Hz 成分を 0.4Hz で揺らす）                     |
| RT-SND-11 | `dishes`（1170・1683・2330Hz の非整数倍音の減衰音を3回。音程は毎回少しずれる）      |
| CR-RZ-07  | `chime`（無名の二音）                                                               |
| CR-RZ-08  | `beat`（高域通過ノイズ + 190Hz の低音を1拍おき、8拍）                               |
| CR-RZ-09  | `shutter`                                                                           |
| CR-SH-05  | `radio`（オリジナルの短い旋律を三角波で、帯域通過ノイズ付き。実在曲は使わない）     |

**素材が要る（5件、いずれも声）**

| 台帳 id   | 備考                                                |
| --------- | --------------------------------------------------- |
| RT-SND-06 | 合成のフォルマント雑音で近似は可能。本命は声素材    |
| RT-SND-07 | 放送の声素材を逆再生。素材は RT-SND-12 と共用できる |
| RT-SND-12 | 声素材 + 帯域制限                                   |
| CR-SH-04  | 群衆の声素材（言葉は聞き取れない）                  |
| CR-SH-06  | 声素材（硬い抑揚、内容は聞き取れない）              |

素材は kako-jun の決定により TTS で制作し、`public/audio/` に置く。`voiceSounds.ts` が `probeVoices`（metadata のみ）で長さを調べ、60秒以上の音源のみ抽選可能にする。デコードは未報告の声のうち必要な1本だけ（見ているカメラの声、無ければ今持っている声をそのまま保持し、カメラ切替で解放・再取得しない。報告・シフト終了・音量0・アンマウントで解放）。再生は終端で1秒重ねてフェードし、カメラ移動・報告・音量0で停止、音量復帰で再開する。取得・デコード失敗時は抽選から外し、5秒から倍々（5・10・20・40秒）で計5回まで再試行して、以後は諦める（恒久失敗扱い）。諦めた後も、保持する声の切替・音量0からの復帰・次のシフトで、改めて読み込みを試す。

### 対応形式と選択方法

各声は `public/audio/{id小文字}.ogg`（Vorbis）と `.m4a`（AAC）の2本を併置する。`voiceUrl` は `new Audio().canPlayType('audio/ogg; codecs="vorbis"') === 'probably'` のときだけ ogg、それ以外（`maybe`・空文字・例外）は m4a を取る。Vorbis を持たない古い iOS Safari を m4a に回すため。**iOS 実機での再生は未確認**（m4a が実際に鳴るかは kako-jun の実機待ち）。

### 素材サイズ（ffprobe 実測）

1本500KB以下・系統（ogg / m4a）別の合計3MB以下を守る。いずれもモノラル 24kHz。m4a は 48kbps 指定（実測約49〜51kbps。`ffmpeg -ac 1 -ar 24000 -c:a aac -b:a 48k`）、ogg は約39〜49kbps。

| 声        | ogg                | m4a                | 長さ   |
| --------- | ------------------ | ------------------ | ------ |
| CR-SH-04  | 413698             | 468193             | 75.1 s |
| CR-SH-06  | 369878             | 401975             | 63.8 s |
| RT-SND-06 | 326174             | 414520             | 66.2 s |
| RT-SND-07 | 442958             | 452152             | 73.3 s |
| RT-SND-12 | 448458             | 468032             | 73.3 s |
| 合計      | 2001166（約2.0MB） | 2204872（約2.2MB） |        |

CR-SH-06 と RT-SND-06 の m4a は当初約91〜95kbps（約760KB）で上限を超えていたため、48kbps 指定で再エンコードした（元の長尺素材が残っていないので現行 m4a からの再エンコード。**音質は 91→48kbps で下がる**。他3本と同じ水準）。`public/audio/` は PWA の precache に入れず（`vite.config.ts` の globPatterns 対象外）、再生時に遅延取得する。
